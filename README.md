# sazondecocina
website para recetas de comida

## Instalacion de Hugo
Pasos siguientes para probar la base:
Instalar Hugo (si aún no lo tienes listo):

En Windows (PowerShell/Chocolatey): choco install hugo-extended

En Mac (Homebrew): brew install hugo

En Linux: sudo apt install hugo

Crear la estructura con los archivos provistos.

Colocar una imagen en content/post/mexico/tacos/img/wallpaper.png.

Ejecutar en la terminal desde la raíz del proyecto:

Bash
hugo server -D
Abrir http://localhost:1313 en tu navegador.
